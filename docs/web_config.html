How to connect

  1. Plug the Loopster into this computer with a USB cable.
  2. Close any other program that might be talking to it (a DAW, a MIDI monitor).
  3. Click Connect above and pick the Loopster from the list.
  4. While connected, the Loopster's screen shows WEB CONFIG and its buttons are paused until you disconnect.
Browser note: connecting works in Chrome and Edge on a computer — Safari, Firefox, and phones can't connect to USB devices.

Firmware Update

Checking…
Step 1 · Restart into update mode

The Loopster keeps playing until you begin. Clicking below restarts it into update mode: it disconnects from this page and a drive named RPI-RP2 appears on your computer (macOS can take ~10 s).

Step 2 · Copy the firmware over

Once the RPI-RP2 drive appears, click below and select it in the folder dialog. The firmware is copied onto the device for you, and the Loopster reboots itself when the copy finishes.

I don't see the RPI-RP2 Drive

Or update manually:

  1. Click Download below and confirm — the file downloads and the Loopster restarts into update mode.
  2. Drag the downloaded .uf2 file onto the RPI-RP2 drive.
  3. The Loopster reboots automatically when the copy finishes — no eject needed.
  4. Reconnect here to confirm it came back up.

Or open the latest release page on GitHub ↗

Don't see the RPI-RP2 drive? Unplug the USB cable, hold the BOOTSEL button on the board while plugging it back in, and it will appear. The physical button always works even if this software path fails.
